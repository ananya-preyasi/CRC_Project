# CRC_Project

Retrospective cohort study investigating the association between chronic corticosteroid exposure and colorectal cancer (CRC) in adults aged 18-49, using the HCUP National Inpatient Sample (NIS) 2023 dataset.

## Project Structure

```
CRC_Project/
├── configs/                          # Configuration files (placeholder)
├── outputs/
│   ├── feature_screening_results.csv # Univariate screening results (20 variables)
│   └── variable_profile.csv          # Data profiling and variable type suggestions
├── scripts/
│   ├── 00_check_dataset.py           # Validates dataset key uniqueness
│   ├── 01_build_cohort.py            # Builds CRC cohort with inclusion/exclusion criteria
│   ├── 02_logistic_regression.py     # Multivariate logistic regression
│   ├── 03_feature_screening.py       # Automated feature screening pipeline
│   ├── 03_profile_variables.py       # Variable profiling and type classification
│   └── feature_screening_utils.py    # Shared utility functions
├── requirements.txt
├── README.md
└── .gitignore
```

## Analysis Pipeline

| Step | Script | Description |
|------|--------|-------------|
| 0 | `00_check_dataset.py` | Validates `KEY_NIS` uniqueness in the NIS Core dataset |
| 1 | `01_build_cohort.py` | Filters ages 18-49, identifies CRC cases (ICD-10 C18-C20), applies exclusion criteria, flags steroid exposure |
| 2 | `02_logistic_regression.py` | Runs multivariate logistic regression (CRC ~ steroid + age + sex + elective + payer + income) |
| 3a | `03_profile_variables.py` | Profiles all variables: data types, missingness, suggested classifications |
| 3b | `03_feature_screening.py` | Univariate screening via chi-square, mutual information, and logistic regression |

## Clinical Domain

- **CRC Cases:** ICD-10 codes C18 (colon), C19 (rectosigmoid), C20 (rectum) as principal diagnosis
- **Exclusions:** Benign polyps (D12), anal cancer (C21), liver metastases (C78.5), hereditary syndromes, IBD
- **Steroid Exposure:** 18 ICD-10 codes for conditions requiring chronic corticosteroid therapy

## Data Notes

- The raw HCUP NIS 2023 Core dataset is **not included** in this repository. It must be obtained separately from [HCUP](https://www.hcup-us.ahrq.gov/).
- Patient-level cohort files (`outputs/cohort.csv`, `outputs/cohort_principal_dx.csv`) are **excluded** from version control to protect patient privacy. These are generated by `01_build_cohort.py`.
- Only summary-level outputs (`variable_profile.csv`, `feature_screening_results.csv`) are tracked.
